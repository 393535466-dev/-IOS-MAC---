通用 Mac 遥控器 · 产品方案 · 2026-11-03

龙虾脑 LobsterBrain

一句话指挥你的电脑 —— 手机输入自然语言，Mac 替你干活，结果回到手机

1项目定位与用户价值

一句话定位：龙虾脑是一个「手机遥控电脑」的 AI 执行入口 —— 用户在手机网页输入一句自然语言，系统把意图解析成可执行任务，驱动一台 Mac 真实操作，并把执行状态与结果实时回传到手机。

目标用户

  • 人不在电脑前，但需要电脑干活的人（远程触发下载 / 搜索 / 整理）
  • 不想学复杂软件操作的人（用说话代替点菜单）

核心价值主张

  • 自然语言 = 操作系统入口：降低电脑操作门槛
  • 异步执行：发起后可离开，状态推送式回传，不用盯着
  • 过程透明：每一步做什么、成没成功，全程可见
为什么叫「龙虾脑」：龙虾用一套简单的神经回路就能稳定驱动复杂行为 —— 我们想让电脑也拥有一颗这样「听得懂人话、按套路办事」的简单大脑。

起步场景：「搜索一部热门电影并播放相关视频」—— 意图单一清晰、结果可感知、失败路径真实（权限 / 网络缺失），用于验证完整闭环。当前版本已扩展为通用 Mac 遥控器：一句话即可驱动打开应用、自动输入、发微信、系统操作、搜索任意平台，并在手机端用触控板直接操控 Mac 光标（详见第 4 节能力清单）。

2产品闭环流程（已在当前版本中实现）

用户输入手机网页文本框 + 示例指令一键填充，降低空白输入门槛
执行状态四阶段时间轴（pending / running / done / failed 四态可视化），running 态呼吸动画 + 已进行秒数
成功反馈绿色结果卡：识别到的影片、Mac 端实际发生了什么、下一步指引
失败反馈红色结果卡 + 具体异常原因 + 常见原因提示 +「再试一次」入口；失败任务落库供运营排查
运营看板/dashboard：累计任务、成功率、平均耗时、今日新增、近 7 日任务量柱状图、最近任务明细（每 5s 刷新）

5体验边界（当前版本已突破 MVP）

当前版本已做到

  • 通用指令闭环：打开应用 / 搜索 / 自动输入 / 发微信 / 系统操作
  • 规则引擎优先 + 可选 LLM 混合解析，明确指令秒级响应
  • 向任意 macOS 应用自动输入（微信 / 豆包 / WorkBuddy / 浏览器等）
  • 手机触控板驱动 Mac 真实光标 + 一句话发微信
  • 语音输入（HTTPS 安全上下文）+ 四阶段状态透明回传
  • 局域网令牌鉴权 + 自定义密码，本机免验证
  • 首次配置向导：权限 / 自启 / 固定入口 / 证书 / 语音一次配好，IP 变化可自检并一键重签
  • 可插拔 ASR 适配层（默认关闭，键盘听写为主力）
  • 短词净化 + 轻量应用级指代（「把它关了」「再打开」），不依赖服务端 ASR

当前版本仍不做

  • 多意图 / 多步复杂任务编排（如「下载并压缩并邮件发送」）
  • 常驻唤醒词 / 完整多轮会话指代（「把它发给刚才那个人」）——需独立 ASR 与会话状态，成本高于收益；当前只做应用级轻量指代
  • 账号体系与多用户隔离 —— 当前为单设备形态
  • 删除文件、批量化破坏性等高危不可逆动作（需产品化后强制二次确认）
  • 公网部署 —— 控制能力依赖 Mac 本机，坚持本地运行不上 Vercel

异常策略分层：解析失败（引导换说法）→ 权限失败（给出具体授权指引）→ 执行失败（网络 / 应用不可用，可重试）→ 降级成功（自动播放不可用时降级为半自动，明确告知用户需要手动补一步）。原则：宁可明确失败，不做静默失败。

7后续产品化路径

1

跑通闭环 已完成

单设备「手机 → Mac → 手机」完整体验与数据链路已打通：自然语言 / 语音 / 触控板三种输入，打开应用、自动输入、发微信、系统操作、搜索等多类执行器，四阶段状态回传 + 运营看板。已交付：Demo + 看板 + 本方案。3.3 已完成从 MVP 到产品的关键包装：本机应用自发现 + 真实图标、三条语音路径与结果播报、未安装应用智能兜底、主屏 App 化。

2

更聪明、更稳 1-2 周

  • 规则解析 → LLM 意图解析 + 函数调用（Function Calling），支持任意「查 - 开 - 放 - 传」类指令
  • 执行器插件化：浏览器之外接入 Finder / 播放器 / 终端，权限统一收口为一套「授权中心」
  • WebSocket 推送替代轮询；失败任务自动重试 + 原因分类打点
3

可运营、可复制 1 个月

  • 多设备绑定（一台手机指挥多台 Mac），账号体系 + 设备授权码
  • 任务市场：把高频指令沉淀为「技能卡」，运营可配置热门榜单与推荐位
  • 看板升级：留存曲线、失败归因分布、技能使用排行
4

平台化想象 远期

「龙虾脑」成为跨设备的自然语言操作协议：手机是指挥中枢，电脑是执行四肢，第三方应用以执行器插件接入 —— 最终让每台电脑都长出一颗听得懂人话的「龙虾脑」。

8风险与边界声明

  • 权限与隐私：驱动电脑属于高敏感能力，正式产品必须做到「逐权限明示授权 + 任务级操作日志可回溯」，Demo 仅在用户本机运行，不上传任何数据。
  • 自动化脆弱性：基于选择器的自动点击对页面改版敏感，产品化需转向系统级 API（Accessibility / AppleScript 字典）而非页面 DOM。
  • 滥用边界：当前版本已支持「发消息」等不可逆操作，一律走「操作白名单 + 显式指令确认」底线；删除文件、批量化破坏性等高危动作仍禁用，产品化后强制高危二次确认。
