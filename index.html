规则引擎优先解析（明确指令秒级、零延迟），模糊指令回落可选大模型。以下能力均已实机验证。

产品逻辑 · 它是怎么工作的

手机到 Mac，一条本地闭环

所有解析与执行都发生在你的 Mac 本机：服务监听局域网，手机通过浏览器发指令，服务端把意图变成真实的系统调用，再把每一步状态回传。

1

解析

规则引擎优先，明确指令（打开 / 搜索 / 截屏）秒级命中；模糊指令回落大模型。中文名自动映射到真实应用名。

2

规划

把意图拆成可执行步骤；复合指令（"打开微信——输入你好"）逐段规划，明确每一步要做什么。

3

执行

通过 open / osascript / screencapture / mousectl 真实驱动 Mac：打开应用、自动输入、点击、截屏、移动光标。

4

回传

每个阶段的状态、最终结果与失败原因都推回手机；宁可明确失败，也绝不静默吞错。

产品需求 · 解决什么问题

它要替你扛住的五个麻烦

龙虾脑不是又一个远程桌面，而是把「用电脑」这件事，从层层菜单点击，坍缩成一句话。

痛点龙虾脑的应对
人不在电脑前，却需要它干活手机即遥控器：同 Wi-Fi 即可远程触发 Mac 去搜片、下载、打开工程。
操作门槛高非技术用户 / 长辈不会用复杂软件与快捷键——一句话完成「打开应用并输入」等多步操作。
传统自动化是黑盒宏 / 脚本失败无提示、不透明——四阶段时间轴 + 看板，每步状态可感知。
远程控制方案重需装客户端、注册账号、担心数据出公网——零依赖单文件、本地运行、令牌鉴权，数据不出本机。
缺语音 / 触控手机只能打字发指令，手忙时仍不便——支持 语音输入 + 手机触控板 直接操控 Mac 光标。

使用说明

三步，把你的 Mac 交给一句话

1

启动服务

终端运行 node app.js，或直接双击 start.command（用「终端」启动，确保辅助功能授权对象明确）。启动后终端会打印手机端地址。

2

手机连接

手机与 Mac 同 Wi-Fi，浏览器打开打印的局域网地址。首次请在 Mac 本机 http://localhost:8787/config 复制带令牌的「手机链接」加到主屏幕；语音需走 https://...:8788 并信任证书。

3

授权辅助功能

自动输入 / 点击依赖 macOS「辅助功能」权限。在 系统设置 → 隐私与安全性 → 辅助功能 开启运行 node 的程序，并完全退出重开。未授权时手机端会显示醒目引导，而非静默失败。

4

发指令 / 看数据

手机输入框打字，或按住说话用语音说一句话；状态实时回传。看板 /dashboard 含成功率、耗时与明细，每 5 秒刷新。

# 启动（需 Node 18+）
node app.js

# 或用大模型兜底模糊指令（可选）
export LLM_BASE_URL=https://api.example.com/v1
export LLM_API_KEY=sk-xxxx
export LLM_MODEL=gpt-4o-mini
node app.js

# 自定义令牌 / 密码
POST /api/auth/reset { "token": "你的固定密码" }

# 看板
open http://localhost:8787/dashboard

令牌说明：首次启动随机生成并写入 auth.json（已 gitignore）。局域网访问须带令牌（?t=TOKEN），本机 localhost 免验证。

安全性

数据不出本机，权限清晰可控

控制权留在你的 Mac 上，云平台拿不到你的电脑，因此坚持本地运行 + 令牌鉴权。

局域网令牌鉴权

任意 /api/ 访问须携令牌；本机视为本人设备免验证。令牌经 URL 或请求头透传，手机页自动带。

不部署到公网

不部署 Vercel / 无服务器平台：控制依赖服务跑在你的 Mac 上，上云只剩空壳。远程访问走「Mac 常驻 + 加密隧道 + 令牌」。

辅助功能授权可控

自动输入 / 点击依赖系统辅助功能开关，用户显式授权且明确知道授权对象；未授权即降级为「复制 + 手动粘贴」。

高危操作边界

删除文件等不可逆动作默认禁用；已支持的「发消息」严格走「显式指令 + 操作日志」，产品化后以白名单 + 二次确认为底线。

数据本地化

任务存于本地 tasks.json；auth.json / llm-config.json（含 Key）均 gitignore，不会进入公开仓库。

零依赖最小化攻击面

仅用 Node 内置模块，无需 npm install；不拉外部运行时，部署简单、可被审计。

设计决策 · PM 视角

为什么是这些取舍

规则引擎优先 + 大模型兜底

明确指令走本地规则，秒级、零成本、零延迟；仅模糊 / 开放指令回落模型。结果：大多数时候「感觉不到 AI，但指令依然灵」。

本地优先，不部署公网

控制能力依赖服务跑在你的 Mac 上，云平台拿不到你的电脑。坚持本地运行 + 令牌鉴权，远程走「Mac 常驻 + 加密隧道 + 令牌」。

过程透明与显式失败

任何阶段失败都中止并推送原因 + 重试引导，不静默吞错；四阶段时间轴让每一步可被感知。

多模态输入并存

文字、语音、触控板三种入口并存，覆盖「手忙 / 不想打字 / 精细操控」不同情境。

安全边界前置

自动输入 / 点击依赖用户显式开启的辅助功能授权；删除文件等高危不可逆动作默认禁用，发消息走显式指令 + 操作日志。
