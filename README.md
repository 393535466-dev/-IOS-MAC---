# 龙虾脑 LobsterBrain

> 手机一句话（或一句语音）→ 智能解析 → 驱动 Mac 执行 → 手机实时回传状态与结果。
> 让电脑长出一颗「听得懂人话、按套路办事」的简单大脑。

**产品落地页**：[`index.html`](index.html) —— 从产品逻辑、需求痛点、应用场景、使用说明到安全性的一体化介绍页（设计参考 Brex 风格：白混凝土画布 + 单一 ember 强调色）。克隆仓库后直接用浏览器打开即可。

## 一、产品定位与设计理念

龙虾脑是一个「手机遥控电脑」的 AI 执行入口。用户在手机网页输入自然语言或语音，系统把意图解析成可执行任务，驱动一台 Mac 真实操作（打开应用、自动输入、发消息、系统控制、搜索），并把每一步的状态与最终结果实时回传到手机。

**为什么叫「龙虾脑」**：龙虾用一套简单的神经回路就能稳定驱动复杂行为。我们想让电脑也拥有一颗这样「听得懂人话、按套路办事」的简单大脑——不追求拟人思考，只追求「指令清晰、执行可靠、过程可见」。

**三个设计支点**
- **自然语言 = 操作系统入口**：用说话/打字替代层层菜单点击，降低电脑操作门槛。
- **异步执行**：发起后可离开，状态以「推送式」回传，不用盯着屏幕。
- **过程透明**：解析 → 规划 → 执行 → 回传，四阶段全程可见，宁可明确失败也不静默失败。

## 二、产品解决的问题

| 痛点 | 说明 | 龙虾脑的应对 |
|------|------|--------------|
| 人不在电脑前，但需要电脑干活 | 下载、搜索、整理、发消息往往得坐到电脑前 | 手机即遥控器，同 Wi-Fi 即可远程触发 Mac |
| 操作门槛高 | 非技术用户 / 长辈不会用复杂软件与快捷键 | 一句话即可完成「打开应用并输入」等多步操作 |
| 传统自动化「黑盒」 | 宏 / 脚本失败无提示、不透明、难排查 | 四阶段时间轴 + 运营看板，每步状态可感知 |
| 远程控制方案重 | 需装客户端、注册账号、担心数据出公网 | 零依赖单文件、本地运行、令牌鉴权，数据不出本机 |
| 语音 / 触控缺失 | 手机只能「打字发指令」，手忙时仍不便 | 支持语音输入 + 手机触控板直接操控 Mac 光标 |

> 自然语言可识别的软件清单与口语化说法，详见 [软件与语言清单.md](软件与语言清单.md)。

## 三、核心能力

| 能力域 | 能力 | 触发示例 |
|--------|------|----------|
| 指令理解 | 自然语言解析（规则优先，明确指令秒级；模糊指令回落可选大模型） | 「搜索《流浪地球》预告片并播放」 |
| 指令理解 | 语音规范化（口语 → 清晰指令） | 「那个帮我搜一下流浪地球的预告片然后放一下」 |
| 指令理解 | 复合指令逐段执行 | 「打开微信——输入你好」 |
| 指令理解 | 应用名智能识别（中文名 → 真实应用名） | 「打开谷歌浏览器」「打开 WorkBuddy」 |
| Mac 操控 | 打开应用 / 文件 / 文件夹 / 网站 / 网址 | 「打开微信」「打开下载文件夹」 |
| Mac 操控 | 向任意应用自动输入 | 「打开豆包——输入帮我写一份周报」 |
| Mac 操控 | 系统操作 | 「截个屏」「音量调大一点」「锁屏」 |
| Mac 操控 | 任意平台搜索 | 「在知乎搜大模型微调」「百度一下 Python 异步」 |
| 通讯 | 一句话发微信 | 「给文件传输助手发微信：今晚加班」 |
| 通讯 | 发短信（Messages） | 「发短信给妈妈：我到家了」 |
| 鼠标控制 | 手机触控板驱动 Mac 光标移动 / 点击 | 手机端触控板直接操控电脑指针 |
| 鼠标控制 | 滚轮滚动页面 | 触控板旁滚轮条上下滑动 / ▲▼ 单步按钮 |
| 语音输入 | 按住说话，实时「正在听」反馈 | 手机语音输入 |
| 安全 | 局域网令牌鉴权 + 自定义密码 | 手机链接内置令牌，本机免验证 |
| 可观测 | 四阶段状态回传 + 运营看板 | /dashboard 查看成功率、耗时、明细 |

支持平台：百度 / Google / B站 / 优酷 / 爱奇艺 / 腾讯视频 / YouTube / 豆瓣 / 知乎 / 微博 / GitHub / 淘宝 / 京东。

## 四、应用场景

- **远程触发**：人躺在沙发上 / 在厨房，用手机让 Mac 去 B 站搜片、下载资料、打开某个工程。
- **解放双手**：手上有活（做饭、健身）时，用语音让电脑「打开豆包——记一下待办」。
- **跨应用输入**：不必切到电脑前，一句话在微信、豆包、WorkBuddy 等任意应用里完成输入。
- **手机当触控板 / 滚轮**：临时没有鼠标，用手机屏幕移动并点击 Mac 光标，滚轮条上下滑动滚动页面。控制板固定置顶，软键盘弹出也不会被顶出屏幕。
- **一键联络**：走路时用语音「给妈妈发微信：我到家了」，消息即时送达。
- **团队 / 演示**：运营看板沉淀任务数据，便于复盘「有哪些指令、成功率如何」。

## 五、产品设计的几个关键决策（PM 视角）

- **规则引擎优先 + 大模型兜底**：明确指令（打开 / 搜索 / 截屏…）走本地规则，秒级响应、零成本、零延迟；仅模糊 / 开放指令回落大模型。结果是「大多数时候感觉不到 AI 的存在，但指令依然灵」。
- **本地优先，不部署公网**：控制能力依赖「服务跑在你的 Mac 上」，云平台拿不到你的电脑，部署到 Vercel 等只剩空壳。因此坚持本地运行 + 令牌鉴权，需要远程访问时走「Mac 常驻 + 加密隧道 + 令牌」。
- **过程透明与「显式失败」**：任何阶段失败都中止并推送原因 + 重试引导，不静默吞错。
- **多模态输入**：文字、语音、触控板三种入口并存，覆盖「手忙」「不想打字」「精细操控」不同情境。
- **安全边界前置**：自动输入 / 点击依赖 macOS 辅助功能授权（用户需显式开启并知道授权给谁）；删除文件等高危不可逆动作默认禁用。

## 六、使用说明

**环境**：macOS（需辅助功能授权）+ Node 18+。

**启动**
```bash
node app.js
```
或直接双击 `start.command`（用「终端」启动，确保辅助功能授权对象明确）。

启动后终端打印：
```
龙虾脑已启动
  手机端（同 Wi-Fi）: http://192.168.x.x:8787
  本机 / 看板:        http://localhost:8787  /dashboard
```

**手机连接**
1. 手机与 Mac 连同一 Wi-Fi，浏览器打开打印的局域网地址。
2. **首次使用请在 Mac 本机打开 `http://localhost:8787/config`，复制带令牌的「手机链接」加到主屏幕书签**（否则手机会被要求输入令牌）。
3. 语音输入需走 HTTPS：手机访问 `https://192.168.x.x:8788`，首次需信任自签名证书。

**令牌与自定义密码**
- 服务首次启动生成随机令牌写入 `auth.json`（已 gitignore，不会上传）。
- 局域网访问必须带令牌（URL `?t=TOKEN` 或请求头 `x-lb-token`），本机 `localhost` 免验证。
- 可设置自己的固定密码：在 `/config` 中「重置令牌」填入自定义密码，或调用 `POST /api/auth/reset`。

**辅助功能授权（自动输入 / 点击的前置条件）**
- 龙虾脑的「自动输入」「鼠标点击」依赖 macOS 「辅助功能」权限。
- 在「系统设置 → 隐私与安全性 → 辅助功能」中，开启**运行 `node app.js` 的那个程序**（终端 / VS Code / WorkBuddy 等），并完全退出该程序重开，授权才会生效。
- 未授权时，手机端会显示醒目的授权引导，而非静默失败。

**运营看板**：`/dashboard` 含累计任务、成功率、平均耗时、近 7 日任务量、动作分布、任务明细，每 5 秒自动刷新。

**接入大模型（可选）**：配置 LLM 后，模糊自然语言走大模型解析；未配置则降级规则引擎，开箱即用。
```bash
export LLM_BASE_URL=https://api.example.com/v1
export LLM_API_KEY=sk-xxxx
export LLM_MODEL=gpt-4o-mini
node app.js
```

## 七、安全性

- **局域网令牌鉴权（默认开启）**：手机 / 其他设备访问任意 `/api/` 必须携带令牌；本机视为本人设备免令牌。令牌传递：`?t=TOKEN` 或 `x-lb-token` 头，手机页已自动透传。
- **不部署到 Vercel / 无服务器平台**：控制能力依赖服务运行在你的 Mac 上，云平台拿不到你的电脑，部署上去只剩空壳网页。需远程访问请走「Mac 常驻 + 加密隧道 + 令牌」。
- **辅助功能授权清晰可控**：自动输入 / 点击依赖系统辅助功能开关，用户显式授权且明确知道授权对象；未授权即降级为「复制 + 提示手动粘贴」，不绕过系统。
- **高危操作边界**：删除文件等不可逆动作默认禁用；当前已支持的「发消息」属不可逆操作，也严格走「显式指令 + 操作日志」，产品化后以「操作白名单 + 二次确认」为底线。
- **数据本地化**：任务数据存于本地 `tasks.json`，本 Demo 不上传任何数据；`auth.json` / `llm-config.json`（含 Key）均已 gitignore，不会进入公开仓库。

## 八、目录结构与技术说明

```
.
├── app.js                 # 单文件服务（API + 手机页 + 看板 + 执行引擎 + 令牌鉴权）
├── bin/
│   └── mousectl.py        # 手机触控板/滚轮→Mac 鼠标的零依赖控制（python3 + CoreGraphics）
├── cert/                  # 自签名 SSL 证书（HTTPS/语音用，已 gitignore）
├── start.command          # 双击即用「终端」启动（确保辅助功能授权对象明确）
├── 龙虾脑产品方案.html      # 产品方案（用户价值/流程/边界/指标/规划/能力清单）
├── package.json
├── LICENSE
├── llm-config.json        # 大模型配置（含 Key，已 gitignore）
├── auth.json              # 局域网访问令牌（首次启动生成，已 gitignore）
└── tasks.json             # 运行时自动生成，任务落库
```

- **零依赖**：仅用 Node 内置 `http` / `fs` / `child_process` / `os`，无需 `npm install`。
- **真实执行**：`open` 唤起应用 / 文件夹 / 网址，`osascript` 调系统事件与 AppleScript，`screencapture` 截图，`pbcopy` 剪贴板，`bin/mousectl.py` 控制光标。
- **语音**：基于浏览器原生 Web Speech API，需 HTTPS 安全上下文。
- **数据存储**：`tasks.json` 本地落库，重启不丢。
