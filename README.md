# 龙虾脑 LobsterBrain

> 手机一句话（或语音）→ 智能解析 → 驱动 Mac 执行 → 手机端实时回传状态与结果。

一个「手机遥控电脑」的 AI 执行入口 Demo：用户在手机网页输入一句自然语言，系统把意图解析成可执行任务，驱动一台 Mac 真实操作，并把执行状态与结果实时回传到手机。零依赖、单文件、开箱即用。

## 为什么叫「龙虾脑」

龙虾用一套简单的神经回路就能稳定驱动复杂行为 —— 我们想让电脑也拥有一颗「听得懂人话、按套路办事」的简单大脑。

## 能力矩阵

| 动作 | 说明 | 示例指令 |
|------|------|----------|
| `search` | 在任意平台搜索任意关键词 | 百度一下 Python 异步编程 / 在知乎搜大模型微调 |
| `play` | 视频站搜索并尝试自动播放 | 搜索《流浪地球》预告片并播放 / 在B站搜沙丘2的花絮 |
| `open` | 打开 Mac 应用 / 文件夹 / 网站首页 / 网址 | 打开微信 / 打开下载文件夹 / 打开GitHub |
| `rating` | 豆瓣查电影评分 | 帮我查一下奥本海默的评分 |
| `system` | 音量±/静音、亮度（开显示设置）、截图、锁屏、清废纸篓（需确认）、系统设置 | 截个屏 / 音量调大一点 / 锁屏 |
| `note` | 记内容到剪贴板并打开备忘录 | 把明天开会带电脑记到备忘录 |

支持平台：百度 / Google / B站 / 优酷 / 爱奇艺 / 腾讯视频 / YouTube / 豆瓣 / 知乎 / 微博 / GitHub / 淘宝 / 京东。

## 快速开始

```bash
# 需 Node 18+
node app.js
```

启动后终端会打印：

```
龙虾脑 v3 已启动
  手机端（同 Wi-Fi）: http://192.168.x.x:8787
  本机 / 看板:        http://localhost:8787  /dashboard
```

- **手机端**：手机连同一 Wi-Fi，浏览器打开打印的局域网地址。**首次使用请在 Mac 本机打开 `http://localhost:8787/config` 复制带令牌的「手机链接」加到主屏幕**（否则手机会被要求输入令牌）。
- **运营看板**：`/dashboard`，含累计任务、成功率、平均耗时、近 7 日任务量、动作分布、任务明细，5 秒自动刷新
- **配置页**：`/config`（本机），可接入大模型、查看辅助功能授权状态、查看/重置局域网访问令牌。

## 语音输入

手机用 Safari 或 Chrome 打开页面，点输入框右侧的 🎤 即可说话：
- 实时显示「正在听…」和识别中的文字
- 说完自动填入输入框，可直接执行
- 基于浏览器原生 Web Speech API，无需后端

## 智能：规则引擎 + 可选大模型

默认使用内置**增强规则 NLU**：识别「动作 × 平台 × 内容类型 × 对象」四维，开箱即用。

如需处理完全任意的自然语言，可接入任何 OpenAI 兼容的大模型：

```bash
export LLM_BASE_URL=https://api.example.com/v1
export LLM_API_KEY=sk-xxxx
export LLM_MODEL=gpt-4o-mini
node app.js
```

配置后意图解析自动走大模型（Function Calling / JSON 输出），未配置则降级规则引擎。

## 产品闭环

```
手机输入/语音 → 意图解析 → 任务规划 → 驱动 Mac 执行 → 状态+结果回传手机
                    └── 异常分支：任一阶段失败即中止，推送失败原因 + 重试引导，落库进看板
```

四阶段状态时间轴：意图解析 → 任务规划 → 驱动 Mac 执行 → 结果回传，每阶段 pending/running/done/failed 四态可视化。

## 技术说明

- **零依赖**：仅用 Node 内置 `http` / `fs` / `child_process` / `os`，无 npm install
- **真实执行**：`open` 唤起浏览器/应用/文件夹，`osascript` 调系统音量/AppleScript，`screencapture` 截图，`pbcopy` 剪贴板
- **B站自动播放**：通过 AppleScript 点击首个视频（需 Chrome 开启「视图 → 开发者 → 允许 Apple 事件中的 JavaScript」），不可用时优雅降级为「轻点即可播放」
- **数据存储**：`tasks.json` 本地落库，重启不丢；看板预置演示数据便于首屏展示

## 安全与边界

- **局域网访问令牌（默认开启）**：服务首次启动会生成随机令牌并写入 `auth.json`（已加入 `.gitignore`，**不会上传到 GitHub**）。手机/其他设备访问任意 `/api/` 接口**必须**携带令牌；本机（`localhost`）视为本人设备，免令牌。
  - 在 Mac 本机打开 `http://localhost:8787/config` 配置页，可查看令牌与「手机链接」（链接已内置令牌，复制到手机加到主屏幕即可）。
  - 令牌传递方式：URL 参数 `?t=TOKEN` 或请求头 `x-lb-token: TOKEN`；手机页已自动透传，无需手动操作。
  - 重置令牌：配置页点「重置令牌」（会令所有已加主屏幕的手机需重新链接）。
- **不要部署到 Vercel / 其他无服务器平台**：控制能力依赖「服务运行在你的 Mac 上」，**云平台拿不到你的电脑，部署上去只剩空壳网页**。需远程访问请走「Mac 常驻 + 加密隧道（如 Cloudflare Tunnel）+ 令牌」方案。
- 驱动电脑属高敏感能力，正式产品须做到「逐权限明示授权 + 任务级操作日志可回溯」。
- 清空废纸篓等高危操作 Demo 不自动执行，仅提示用户手动确认；不支持删除文件等不可逆操作，产品化后以「操作白名单 + 高危动作二次确认」为底线。
- 本 Demo 仅在用户本机运行，任务数据存于本地 `tasks.json`，不上传任何数据。
