# 龙虾脑 LobsterBrain

> 手机一句话（或一句语音）→ 智能解析 → 驱动 Mac 执行 → 手机实时回传状态与结果。
> 让电脑长出一颗「听得懂人话、按套路办事」的简单大脑。

**产品落地页**：[`index.html`](index.html) —— 从产品逻辑、需求痛点、应用场景、使用说明到安全性的一体化介绍页（设计参考 Brex 风格：白混凝土画布 + 单一 ember 强调色）。克隆仓库后直接用浏览器打开即可。

## 一、产品定位与设计理念

龙虾脑是一个「手机遥控电脑」的 AI 执行入口。用户在手机网页输入自然语言或语音，系统把意图解析成可执行任务，驱动一台 Mac 真实操作（打开应用、自动输入、发消息、系统控制、搜索），并把每一步的状态与最终结果实时回传到手机。

**为什么叫「龙虾脑」**：龙虾用一套简单的神经回路就能稳定驱动复杂行为。我们想让电脑也拥有一颗这样「听得懂人话、按套路办事」的简单大脑——不追求拟人思考，只追求「指令清晰、执行可靠、过程可见」。

**三个设计支点**
- **自然语言 = 操作系统入口**：用说话/打字替代层层菜单点击，降低电脑操作门槛。
- **异步执行**：发起后可离开，状态以「推送式」回传，不用盯着屏幕。
- **过程透明**：解析 → 规划 → 执行 → 回传，四阶段全程可见，宁可明确失败也不静默失败。

## 二、产品解决的问题

| 痛点 | 说明 | 龙虾脑的应对 |
|------|------|--------------|
| 人不在电脑前，但需要电脑干活 | 下载、搜索、整理、发消息往往得坐到电脑前 | 手机即遥控器，同 Wi-Fi 即可远程触发 Mac |
| 操作门槛高 | 非技术用户 / 长辈不会用复杂软件与快捷键 | 一句话即可完成「打开应用并输入」等多步操作 |
| 传统自动化「黑盒」 | 宏 / 脚本失败无提示、不透明、难排查 | 四阶段时间轴 + 运营看板，每步状态可感知 |
| 远程控制方案重 | 需装客户端、注册账号、担心数据出公网 | 零依赖单文件、本地运行、令牌鉴权，数据不出本机 |
| 语音 / 触控缺失 | 手机只能「打字发指令」，手忙时仍不便 | 支持语音输入 + 手机触控板直接操控 Mac 光标 |

> 自然语言可识别的软件清单与口语化说法，详见 [软件与语言清单.md](软件与语言清单.md)。

## 四、应用场景

- **远程触发**：人躺在沙发上 / 在厨房，用手机让 Mac 去 B 站搜片、下载资料、打开某个工程。
- **解放双手**：手上有活（做饭、健身）时，用语音让电脑「打开豆包——记一下待办」。
- **跨应用输入**：不必切到电脑前，一句话在微信、豆包、WorkBuddy 等任意应用里完成输入。
- **手机当触控板 / 滚轮**：临时没有鼠标，用手机屏幕移动并点击 Mac 光标，滚轮条上下滑动滚动页面。控制板固定置顶，软键盘弹出也不会被顶出屏幕。
- **一键联络**：走路时用语音「给妈妈发微信：我到家了」，消息即时送达。
- **团队 / 演示**：运营看板沉淀任务数据，便于复盘「有哪些指令、成功率如何」。

## 五、产品设计的几个关键决策（PM 视角）

- **规则引擎优先 + 大模型兜底**：明确指令（打开 / 搜索 / 截屏…）走本地规则，秒级响应、零成本、零延迟；仅模糊 / 开放指令回落大模型。结果是「大多数时候感觉不到 AI 的存在，但指令依然灵」。
- **本地优先，不部署公网**：控制能力依赖「服务跑在你的 Mac 上」，云平台拿不到你的电脑，部署到 Vercel 等只剩空壳。因此坚持本地运行 + 令牌鉴权，需要远程访问时走「Mac 常驻 + 加密隧道 + 令牌」。
- **过程透明与「显式失败」**：任何阶段失败都中止并推送原因 + 重试引导，不静默吞错。
- **多模态输入**：文字、语音、触控板三种入口并存，覆盖「手忙」「不想打字」「精细操控」不同情境。
- **安全边界前置**：自动输入 / 点击依赖 macOS 辅助功能授权（用户需显式开启并知道授权给谁）；删除文件等高危不可逆动作默认禁用。

## 六、使用说明

**环境**：macOS（需辅助功能授权）+ Node 18+。

**启动**
```bash
node app.js
```
或直接双击 `start.command`（用「终端」启动，确保辅助功能授权对象明确）。

启动后终端打印：
```
龙虾脑已启动
  手机端（同 Wi-Fi）: http://192.168.x.x:8787
  本机 / 看板:        http://localhost:8787  /dashboard
```

**手机连接**
1. 手机与 Mac 连同一 Wi-Fi，浏览器打开打印的局域网地址。
2. **推荐在 Mac 本机打开 `http://localhost:8787/manage`，扫二维码或复制「手机链接」加到主屏幕书签**。（默认已开启「局域网免令牌」，同一 Wi-Fi 下手机即使不带 `?t=` 也能直接用；如需对外更严格，可在 `/manage` 关闭免令牌，此时链接须带令牌。）
3. 语音输入需走 HTTPS：推荐用固定入口 `https://<主机名>.local:8788`（见下节），或 `https://192.168.x.x:8788`。自签名证书需在 iPhone 上装一次为受信任根证书。

**手机页面入口（当前版本）**

| 路径 | 说明 |
|------|------|
| `/`（或 `/m`、`/index.html`） | **默认主入口**：干净重写的遥控页，普通文档流布局，兼容 iOS Safari |
| `/public/phone.html` | **静态备用入口**：主入口的 HTML 快照，走静态路由实时读盘，不依赖服务重载；主入口异常时可用它顶上 |
| `/old` | 旧版界面，仅用于对比 / 回退 |
| `/manage` | Mac 本机控制台：状态、二维码、开机自启、一键重载 |

> `/public/phone.html` 是 `MINI_PAGE` 的静态快照。若后续修改了主页面，用 `node -e` 从 `app.js` 重新导出该文件即可同步（见仓库内注释）。

主入口自带黑白主题开关、紫色语音球、8 个 App 图标、快捷指令、触控板与滚轮；**每一次操作都会在页面顶部显示结果或具体错误**（不再有"界面正常但点不动"的静默失败），顶部状态条每 8 秒自检一次连接。

> 设计说明：旧版曾使用 `body{position:fixed;inset:0}` + `visualViewport` 键盘补偿 + `dvh` 单位，在部分 iOS Safari 上会导致触控板高度塌陷、交互层被裁出视口，表现为"界面显示正常但点哪都没反应"。新版完全避开这些布局，且不含任何全屏遮罩。若语音按钮显示"语音需 HTTPS"，点一下会自动切到 `:8788`（首次需信任证书）。

**HTTPS 证书与固定入口（IP 会变，建议一次配好）**

局域网 IP 由路由器 DHCP 分配，Mac 重连 Wi-Fi / 路由器重启后可能变化，写死 IP 的书签会失效（例如 `192.168.8.45` → `192.168.8.25`）。证书由 `bin/gen-cert.sh` 生成，SAN 同时绑定**不变的 `.local` 域名**和当前 / 历史 IP：

```bash
./bin/gen-cert.sh                              # 重签证书（IP 变了就重跑一次）
./bin/gen-cert.sh 192.168.8.45,192.168.1.9     # 可追加要兼容的旧 IP
```

推荐主屏幕用永久入口（IP 怎么变都不用换）：

```
https://yangxuandeMacBook-Air.local:8788/?t=TOKEN   # 语音（HTTPS）
http://yangxuandeMacBook-Air.local:8787/?t=TOKEN    # 文字（HTTP）
```

`.local` 依赖路由器允许多播 DNS（访客网络 / AP 隔离下可能不通），不通时改用当前 IP 的链接。

**让 iPhone 稳定信任证书（只需一次）**
1. 手机 Safari 打开 `http://192.168.x.x:8787/cert.crt`（公钥文件，无需令牌），按提示下载描述文件。
2. 「设置 → 通用 → VPN 与设备管理」安装 `LobsterBrain` 描述文件。
3. 「设置 → 通用 → 关于本机 → 证书信任设置」开启对 `LobsterBrain` 的**完全信任**。
4. 之后 HTTPS 语音页不再弹「无法验证服务器身份」。

> 重签证书或修改 `app.js` 后，需双击 `start.command` 重载服务才会生效。

**令牌与自定义密码**
- 服务首次启动生成随机令牌写入 `auth.json`（已 gitignore，不会上传）。
- 局域网访问默认开启「**局域网免令牌**」（`TRUST_LAN`，可在 `/manage` 切换）：同一 Wi-Fi 下的手机无需带令牌即可直连，适合个人独享网络；关闭后则必须带令牌（URL `?t=TOKEN` 或请求头 `x-lb-token`），本机 `localhost` 始终免验证。
- 公网 / 陌生网络下建议关闭免令牌，避免同网段他人操控本机。
- 可设置自己的固定密码：在 `/config` 中「重置令牌」填入自定义密码，或调用 `POST /api/auth/reset`。

**辅助功能授权（自动输入 / 点击的前置条件）**
- 龙虾脑的「自动输入」「鼠标点击」依赖 macOS 「辅助功能」权限。
- 在「系统设置 → 隐私与安全性 → 辅助功能」中，开启**运行 `node app.js` 的那个程序**（终端 / VS Code / WorkBuddy 等），并完全退出该程序重开，授权才会生效。
- 未授权时，手机端会显示醒目的授权引导，而非静默失败。

**直输模式（往应用里打字，不会把你困住）**
- 默认「指令模式」。点任一 App 图标 → 打开应用，并让**下一条**输入 / 语音原样粘贴到该应用输入框；**发完自动回到指令模式**，无需手动退出。
- 需要连续打字时，点模式条右侧「连续直输」显式开启；点「退出直输」或说 / 输入「退出直输 / 返回指令」即可退出（包含匹配，带语气词也能识别）。
- **随时都能下指令**：无论哪种直输状态，说 / 输入明确指令（打开 X、截个屏、搜索 X、给 X 发微信…）都会自动识别为指令、立即退出直输，不会被打进输入框。
- 两条强制通道覆盖边界：`指令：内容` 强制按指令执行；`原文：内容` 强制把内容当文字输入（即使它长得像指令）。
- 直输内容**不自动回车发送**；依赖 macOS 辅助功能授权，粘贴会覆盖系统剪贴板。若当前前台应用没有输入框，粘贴不会生效。

**基础指令速查（一句话即可触发）**

| 想做什么 | 说 / 输入 |
|----------|-----------|
| 退出当前应用 | 「关闭」「退出」「退出当前应用」 |
| 退出某个指定应用 | 「关闭微信」「退出抖音」 |
| 关闭当前窗口 / 标签页 | 「关闭当前窗口」「关闭这个标签页」 |
| 最小化 / 隐藏窗口 | 「最小化窗口」「隐藏当前应用」 |
| 全屏切换 | 「全屏」「切换全屏」 |
| 暂停 / 切歌 | 「暂停」「下一首」「上一首」（驱动 Spotify / 音乐 / 网易云 / QQ音乐） |
| 全选 / 复制 / 粘贴 / 撤销 | 「全选」「复制」「粘贴」「撤销」（回车发送用「回车」） |
| 刷新 / 后退 / 前进（浏览器等） | 「刷新」「返回」「前进」 |

> 退出应用（Cmd+Q）**不需要**辅助功能授权即可生效；窗口管理、编辑与导航类（Cmd+W / Cmd+M / 复制粘贴等）需要 macOS 辅助功能授权。关闭 / 退出属于不可逆操作，请确认当前前台应用就是要关闭的那个——尤其**不要在终端正跑着本服务时误说「关闭」**。

**运营看板**：`/dashboard` 含累计任务、成功率、平均耗时、近 7 日任务量、动作分布、任务明细，每 5 秒自动刷新。

**常驻控制台 `/manage`（Mac 本机访问）**
- 一个页面集中解决「用得上、打得开」：显示运行状态（版本 / PID / 运行时长 / 端口 / 令牌）、生成**扫码连接二维码**（手机相机一扫直达，已含令牌）、连接诊断（局域网 IP / 证书 / 辅助功能授权 / 开机自启是否启用）、一键重载与停止。
- 二维码用的是固定的 `.local` 入口，IP 怎么变都能扫。二维码库 `public/qrcode.js` 是零依赖静态资源，运行时不需要 npm。

**扫码连接**
- 在 Mac 本机打开 `http://localhost:8787/manage`，用手机相机扫页面上的二维码即可把带令牌的链接加到主屏幕，免去手动复制粘贴。

**开机自启（launchd，零依赖）**
```bash
bash bin/install-launchd.sh     # 安装：随 Mac 登录自动启动，崩溃后自动重启
bash bin/uninstall-launchd.sh   # 卸载：停止并取消自启
```
- 安装后服务由系统（launchd）托管，不再需要每次双击 `start.command`；日志在 `logs/`。
- 若通过 launchd 启动，请在「系统设置 → 隐私与安全性 → 辅助功能」中授权给 **node 可执行文件本身**（路径见 `logs/launchd.out.log` 首行或 `which node`），而不是终端——因为此时进程不再隶属于终端。
- 代码更新后：launchd 模式下在 `/manage` 点「一键重载」即可；非 launchd 模式仍双击 `start.command` 重载。

**接入大模型（可选）**：配置 LLM 后，模糊自然语言走大模型解析；未配置则降级规则引擎，开箱即用。
```bash
export LLM_BASE_URL=https://api.example.com/v1
export LLM_API_KEY=sk-xxxx
export LLM_MODEL=gpt-4o-mini
node app.js
```

## 七、安全性

- **局域网令牌鉴权（默认开启）**：手机 / 其他设备访问任意 `/api/` 必须携带令牌；本机视为本人设备免令牌。令牌传递：`?t=TOKEN` 或 `x-lb-token` 头，手机页已自动透传。
- **不部署到 Vercel / 无服务器平台**：控制能力依赖服务运行在你的 Mac 上，云平台拿不到你的电脑，部署上去只剩空壳网页。需远程访问请走「Mac 常驻 + 加密隧道 + 令牌」。
- **辅助功能授权清晰可控**：自动输入 / 点击依赖系统辅助功能开关，用户显式授权且明确知道授权对象；未授权即降级为「复制 + 提示手动粘贴」，不绕过系统。
- **高危操作边界**：删除文件等不可逆动作默认禁用；当前已支持的「发消息」属不可逆操作，也严格走「显式指令 + 操作日志」，产品化后以「操作白名单 + 二次确认」为底线。
- **数据本地化**：任务数据存于本地 `tasks.json`，本 Demo 不上传任何数据；`auth.json` / `llm-config.json`（含 Key）均已 gitignore，不会进入公开仓库。

## 八、目录结构与技术说明

```
.
├── app.js                 # 单文件服务（API + 手机页 + 看板 + 执行引擎 + 令牌鉴权）
├── bin/
│   ├── mousectl.py        # 手机触控板/滚轮→Mac 鼠标的零依赖控制（python3 + CoreGraphics）
│   └── gen-cert.sh        # 生成带 .local SAN 的自签名证书（IP 变了重跑）
├── cert/                  # 自签名 SSL 证书 + lobsterbrain.crt（手机安装用，已 gitignore）
├── start.command          # 双击即用「终端」启动（确保辅助功能授权对象明确）
├── 龙虾脑产品方案.html      # 产品方案（用户价值/流程/边界/指标/规划/能力清单）
├── package.json
├── LICENSE
├── llm-config.json        # 大模型配置（含 Key，已 gitignore）
├── auth.json              # 局域网访问令牌（首次启动生成，已 gitignore）
└── tasks.json             # 运行时自动生成，任务落库
```

- **零依赖**：仅用 Node 内置 `http` / `fs` / `child_process` / `os`，无需 `npm install`。
- **真实执行**：`open` 唤起应用 / 文件夹 / 网址，`osascript` 调系统事件与 AppleScript，`screencapture` 截图，`pbcopy` 剪贴板，`bin/mousectl.py` 控制光标。
- **语音**：基于浏览器原生 Web Speech API，需 HTTPS 安全上下文。
- **数据存储**：`tasks.json` 本地落库，重启不丢。
